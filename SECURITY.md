# Responsible Disclosure of Security Vulnerabilities

This is a fork ([fHori/thelounge](https://github.com/fHori/thelounge)) of upstream The Lounge - see [`MIGRATION.md`](./MIGRATION.md) for what's changed.

- ⚠️ **Do not open public issues on GitHub to report security vulnerabilities.**
- **For anything specific to this fork's own changes** (search, storage, the client-side changes described in `CHANGELOG.md`), report it privately via a [security advisory on fHori/thelounge](https://github.com/fHori/thelounge/security/advisories/new) rather than through upstream's contacts below - they can't help with code that only exists in this fork.
- **For anything in code shared with upstream** (i.e. present in `thelounge/thelounge` too), their process still applies:
  - Contact them privately first, in a
    [responsible disclosure](https://en.wikipedia.org/wiki/Responsible_disclosure)
    manner.
  - On IRC, send a private message to any voiced user on their Libera.Chat channel,
    `#thelounge`.
  - By email, send a report to <security@thelounge.chat>.
